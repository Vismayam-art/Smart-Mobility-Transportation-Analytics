# Smart Mobility & Transportation Analytics

## Project Overview
An interactive Microsoft Power BI project designed to analyze urban transportation, mobility performance, passenger demand, traffic conditions, and sustainability across five cities.

## Project Details
- **Tool:** Microsoft Power BI
- **Dataset:** Approximately 200,000 transportation records
- **Cities:** Singapore, Tokyo, London, New York, and Mumbai
- **Period:** January 2024 – December 2025

## Project Milestones
- **Milestone 1:** Data Integration & Modeling
- **Milestone 2:** Geospatial & Transit Analytics
- **Milestone 3:** Demand Intelligence & Mobility Analytics
- **Milestone 4:** Executive Intelligence & Sustainability

## Key Features
- Interactive KPI cards and slicers
- City-wise and vehicle-wise comparisons
- Passenger demand and monthly trend analysis
- Mobility efficiency and sustainability analysis
- Traffic density, speed, emissions, and energy metrics
- Passenger demand forecasting visualization

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
